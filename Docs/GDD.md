# GDD｜《灯影山海》当前竞赛版本

> 当前实现事实（2026-10-31，基线 Run176）：同一主地图内有夸父、精卫、刑天、烛龙四幕，每幕复用三步灯—偶—幕互动。四幕影偶已可见并使用各自姿态及演出片段；正文最初三段夸父方案和附录中的旧构建记录保留为历史，不据此回退当前角色。

## 1. 高概念

《灯影山海》是一段发生在皮影戏台前后的短篇互动演出，以《山海经》“夸父逐日”意象进行创意改编。玩家“以灯为日、以影为夸父”，通过操纵同一盏灯和同一个核心皮影，让原本破碎、沉寂的追日影像重新对齐。每完成一次影子，戏台就恢复一部分声音、色彩与生命；第三次 Holding 成立后，玩家形成的落杖构图直接继续到杖尖接触与林影生长，将前三段影像汇入完整高潮。

本 GDD 只定义当前竞赛 Demo，不预设长篇正式版内容。开发不绑定固定天数，但周期延长不改变“单戏台、三互动、一个高潮”的范围。

三次互动、幕后/幕上构图、声音节奏、真实阴影与调试验收的详细规格见 [`INTERACTION_PRESENTATION_SPEC.md`](INTERACTION_PRESENTATION_SPEC.md)。

单地图剧场布局、环境状态、最小故事背景与美术/性能边界见 [`ENVIRONMENT_NARRATIVE_SPEC.md`](ENVIRONMENT_NARRATIVE_SPEC.md)。

## 2. 玩家身份与目标

玩家是“复演者”而非战斗角色。玩家不需要了解复杂背景，只需从环境、声音和影子中理解：戏台缺少正确的光与影，自己的操作能让演出继续。

即时目标：让当前幕布影子与舞台给出的目标提示接近并稳定。

整体目标：完成三次核心互动，唤醒完整演出。

### 2.1 最小故事背景

故事发生在山野边缘的一座虚构小型影戏剧场。这里久未开演，最后留下的一出《逐日》停在夸父尚未落杖的时刻：灯偏离轨道，皮影、锣鼓与幕布保持未完成状态。

玩家作为“复演者”进入戏台，重新建立灯、偶与幕的关系，把未完的戏演到“弃杖化林”。玩家没有复杂身份，也不承担修复文物或拯救世界的任务。

### 2.2 单地图空间

主地图仍只有一座戏台，但必须读作完整小剧场：

```text
入场短廊
→ 幕后操作区
→ 左右台翼（锣鼓角 / 皮影挂架 / 道具架）
→ 半透明幕布
→ 简化台前观演区
→ 不可探索的远山 / 夜色 / 风景层
```

玩家主要在入场短廊和幕后操作区活动；台前和远景主要服务镜头、空间纵深与高潮展示，不增加导航任务。

## 3. 核心循环

```text
观察目标影形
    ↓
选择灯具或皮影
    ↓
移动 / 旋转 / 切换预设姿态
    ↓
观察幕布实时影子与趋势反馈
    ↓
进入容差并保持短暂时间
    ↓
完成演出片段，解锁下一次互动
```

所有互动必须保留“操作导致影子改变”的直接可见性。不要让 UI 数值取代幕布观察。

## 4. 基础操作

具体键位可按项目输入方案调整，但必须保持以下意图：

| 意图 | 行为 |
|---|---|
| 移动 | 在戏台前后走动，观察幕后实体与幕上效果 |
| 聚焦/交互 | 选中可操纵灯具或皮影 |
| 调整 | 在约束轨道或有限轴上移动/旋转当前对象 |
| 切换姿态 | 在少量预设皮影姿态间切换，不做高自由度骨骼编辑 |
| 取消 | 退出操纵，恢复角色移动 |
| 重置 | 将当前谜题恢复到可完成的初始状态 |

每个可交互物必须有靠近提示、选中反馈、可调整方向提示和边界反馈。

## 5. 体验节奏

| 阶段 | 参考时长 | 目的 |
|---|---:|---|
| 入场与吸引 | 30–60 秒 | 经短廊看见沉寂小剧场、未完《逐日》线索、唯一亮点和第一盏灯 |
| 互动一：引日启幕 | 60–90 秒 | 学会移动灯，让“日”归位并建立光与影的因果 |
| 过渡一 | 20–30 秒 | 第一段声音/色彩恢复，展示结果 |
| 互动二：逐光成形 | 90–120 秒 | 加入夸父皮影的朝向或姿态，形成追日构图 |
| 过渡二 | 20–40 秒 | 舞台继续苏醒，预告更完整的山海画面 |
| 互动三：杖落成林 | 90–150 秒 | 组合已学操作，完成最终影形并触发化林意象 |
| 高潮结尾 | 60–90 秒 | 将玩家成果转化为完整演出与收束 |

目标总时长为 5–8 分钟。若盲测普遍超时，先放宽容差和缩短过渡，不增加提示长文。

### 5.1 环境苏醒节奏

| 状态 | 触发 | 玩家可见变化 |
|---|---|---|
| Dormant | 开场 | 冷灰环境底光；台翼和台前大多藏在暗部；微风与木构声建立沉寂 |
| SunAwakened | 引日启幕完成 | 幕布出现第一层暖金，题签或一侧纹样被照亮，第一声木击唤醒戏台 |
| ChaseAwakened | 逐光成形完成 | 暖色扩到台翼，皮影挂架、锣鼓角与前排长凳出现层次 |
| FinaleReady | 杖落成林 Holding/Resolve | 日轮与杖尖成为焦点，外围不过早全亮，风与低吟聚拢 |
| ForestComplete | 杖尖接触/Finale | 林影越过幕布到立柱、地面或梁架，台前和远景完成显现 |

环境变化只响应现有流程，不形成新的谜题或收集内容。

## 6. 三次核心互动

三段名称与“夸父逐日”母题在当前竞赛版本中固定。具体构图和容差可根据投影测试调整，但交互层级、对象数量与技术复杂度不得扩张。

### 6.1 学习曲线

| 互动 | 学习阶段 | 新增认知 | 玩家控制 | 难度来源 |
|---|---|---|---|---|
| 引日启幕 | 发现规律 | 灯具运动会改变幕上日轮与影子 | 主灯一个主要自由度 | 找到正确方向，不考精细操作 |
| 逐光成形 | 协同控制 | 灯决定光影关系，偶决定角色动作 | 主灯 + 夸父位置/朝向或姿态 | 在两个对象之间协同调整 |
| 杖落成林 | 综合运用 | 已学能力共同完成落杖因果 | 同一主灯 + 同一夸父 + 已学姿态 | 同时满足组合条件并稳定保持 |

三段只增加条件组合，不增加新按键或新交互语法。第三段容差与第二段相当或略宽；戏剧张力来自声音、镜头和影像变化，不来自更苛刻的精度。

### 6.2 互动一：引日启幕

**教学目标**：让玩家理解“移动灯具会改变幕布影子的大小、位置或方向”。

**可控对象**：一盏主灯；山形与夸父皮影位置固定。

**操作自由度**：优先只开放一个主轴，必要时增加有限旋转；使用明显行程边界。

**目标表达**：把主灯形成的圆形亮区/日轮构图移动到山口目标区域，让沉寂幕布第一次出现“日”的意象。目标提示采用山纹缺口或残缺日轮，融入演出而不使用复杂仪表盘。

**完成条件**：灯具参数进入目标容差，影子稳定保持约 0.8–1.5 秒。

**反馈**：

- 接近时，目标纹样、音色或幕布光晕逐步增强；
- 进入有效区后出现短暂稳定反馈；
- 完成时锁定当前结果，触发第一段演出。

**失败与恢复**：没有死亡。离开范围只会减弱反馈；玩家随时可重新调整或重置。

### 6.3 互动二：逐光成形

**教学目标**：在已理解灯具的基础上，加入夸父皮影变量，理解“幕后两个简单调整可以在幕上合成追逐太阳的完整形象”。

**可控对象**：主灯 + 一个关键皮影。

**操作自由度**：灯具沿已学轨道调整；皮影只开放位置/朝向之一与少量预设姿态，避免自由骨骼操控。

**目标表达**：目标不是纯粹描边临摹，而是让夸父的奔跑/伸手姿态与日轮形成清楚的“逐日”关系。提示只显示残缺山纹、运动方向或构图锚点，保留玩家观察真实影子的空间。

**完成条件**：灯具与皮影参数共同进入容差；姿态 ID 正确；保持时间满足要求。

**递进方式**：玩家需要在灯和皮影之间来回调整，但任一变量都不能精细到难以控制。可使用软吸附或分段反馈。

**完成回报**：第二段动画从玩家形成的追日剪影自然接续，夸父向前迈步、山纹后移、鼓点与呼吸声增强，不硬切到无关镜头。

### 6.4 互动三：杖落成林

**教学目标**：组合前两次操作，让玩家完成一幅具有高潮感的最终影形。

**可控对象**：仍只使用已认识的主灯和核心皮影；可以按顺序解锁两个调整阶段，避免同时操纵过多对象。

**操作自由度**：复用互动一、二的移动、旋转或姿态切换，不新增新输入系统。

**目标表达**：玩家先让日轮落入最终位置，再把夸父切换到持杖/落杖姿态并完成构图。画面同时保留前两次的日轮、山形和追逐方向，让玩家感到自己在完成故事终章，而不是解第三道孤立机关。

**完成条件**：日轮、夸父位置/朝向、落杖姿态等全部启用条件进入更宽而稳定的最终容差，并连续保持。允许用滞回、软吸附或分段停靠保护已经接近正确的条件，但最终组合仍必须由玩家完成。

**直接因果回报**：Holding 完成时冻结玩家形成的灯、偶和姿态状态，不瞬移到另一套预制构图。落杖动作从当前画面继续；杖尖接触幕布落点的同一帧触发木击/低鼓重音和林影生长。树林必须从同一个接触点展开，再带动幕布、色彩、风声、枝叶声和镜头进入高潮。Sequencer 只编排这一因果链，不决定谜题完成，也不增加第四个谜题。

**玩家感知验收**：盲测者应表述为“我把杖落下后长出了树林”，而不是“我通关后播放了树林动画”。

## 7. 高潮结尾

高潮是玩家操作的放大与回声，不是独立播放的宣传片。

推荐演出结构：

1. 玩家完成第三次影形，系统冻结该次 Resolved Snapshot 和当前可见 Transform；
2. 落杖动作从玩家最终构图继续，杖尖接触帧成为声画同步锚点；
3. 林影从同一个杖尖落点展开，随后日轮、山形、奔跑姿态以层叠、掠过或接力方式回响，灯光、幕布材质、音乐和环境粒子进入最高点；
4. 镜头保持能看清“幕后实体—幕上影像”关系，至少一次揭示两侧；
5. 演出落幕，给出简短标题/结束提示和重新体验入口。

高潮建议控制在 60–90 秒，避免超过玩家实际操作总时长。

### 7.1 双重空间与镜头

- 自由观察使用角色基础相机；进入操纵后，平滑切换到稳定的幕后三分之四舞台机位；
- 操纵机位必须让幕布保持主要阅读面积，同时在前景或侧景保留主灯、皮影或操杆中的至少一项；
- 短过渡与高潮可由 Cine Camera + Sequencer 接管，但任一时刻只能有一个最终 POV 所有者；
- Finale 必须保留一个不切镜的因果镜头：最终影形 → 杖尖落点 → 林影生长；
- 过场正常结束、跳过或异常中断都要恢复正确 View Target、输入和 UI；
- 不使用强景深、持续抖动或极端广角妨碍影子阅读。

### 7.2 声音节奏

| 阶段 | 主要声音 | 节奏作用 |
|---|---|---|
| 沉寂/探索 | 微风、木结构、轻脚步 | 留出空间并引向戏台 |
| 引日启幕 | 灯架摩擦、稀疏木击、单层鼓脉冲 | 帮助发现“灯动影变” |
| 逐光成形 | 操杆/关节、追逐脚步、呼吸、逐渐加密的鼓点 | 表达两个对象协同与追逐感 |
| 杖落成林 | 风声聚拢、低声吟唱、克制鼓点 | 聚拢高潮但不提前泄露 |
| 杖尖接触 | 唯一强木击/低鼓重音 | 把玩家动作与成林首帧锁在一起 |
| 化林高潮 | 枝干伸展、叶片簌动、完整吟唱与锣鼓层 | 完成从人造戏台到神话自然的转化 |

脚步与杖尖接触使用 Animation Notify 或 Sequencer 明确同步点；谜题进度只转换成有限的“远/近/有效”音频状态，不得每帧播放 One Shot。声音不能成为唯一提示，静音时仍须可通关。未经考证和授权，不把原创非语义人声称为特定地域传统唱腔。

## 8. 引导与反馈

引导优先顺序：场景构图 > 动画/光 > 音效 > 简短文字。

### 必备状态反馈

- 可交互：轮廓、光点、材质或轻微运动提示；
- 已选中：对象高亮且输入方向清晰；
- 接近目标：连续增强，不只在成功瞬间提示；
- 达到目标：稳定倒计时或呼吸效果；
- 成功：锁定、音效、画面变化和下一目标同时成立；
- 超出边界：阻尼/停靠与短促反馈，不静默失效；
- 重置：明确但不过度打断。

声音反馈与视觉反馈必须表达相同状态：接近时逐层增强，Holding 时稳定持续，取消时自然回落，Resolve 只产生一次明确重音。

提示文字应采用动作语言，例如“移动灯，让影子落入残缺的轮廓”，避免解释底层参数。

## 9. 难度与辅助

- 谜题一只考一个主要变量；
- 谜题二考两个低自由度变量；
- 谜题三组合已知变量，但容差不应更苛刻；
- 连续约 20–30 秒没有有效进展时，可增强目标提示或扩大软吸附；
- 所有谜题都允许一键重置；
- 镜头、角色或物体不得遮挡关键幕布区域；
- 色彩反馈之外至少提供亮度、形状或声音反馈。

## 10. 叙事边界

叙事通过戏台状态、环境线索、音画恢复和短字幕传达。当前竞赛版本不建立复杂世界观词条。

可以保留的最小叙事弧：

- 沉寂：戏台失去光与声音；
- 引日：玩家发现移动灯能够让“日”归位并唤醒影子；
- 逐光：夸父剪影与日轮逐步形成追逐关系；
- 成林：手杖落点生长林影，人与灯、偶与影重新建立联系。

### 10.1 叙事呈现层级

1. **环境与动作层**：不看文字也能理解“久未开演—未完逐日—玩家复演”；
2. **短题签层**：开场最多两句，段间只显示“引日启幕—逐光成形—杖落成林”；
3. **完整说明层**：文化来源、创意改编、技术与许可放在菜单、片尾或参赛材料。

开场建议：

```text
灯熄以后，影停在了逐日途中。
把这出未完的戏，重新演完。
```

结尾将原典和团队创作分开标注：

```text
“弃其杖，化为邓林。”——《山海经·海外北经》
灯影未息，故事仍在人手中。——团队创作表达
```

### 10.2 环境叙事边界

- 可以使用《逐日》题签、皮影挂架空槽、灯轨磨损、未响锣鼓、未展开林纹和窗外远山建立背景；
- 场景应读作“久未开演、仍可复演”，不使用坍塌废墟、鬼影观众等恐怖符号改变作品类型；
- 不新增 NPC、日记收集、对话树、家族/师徒关系或分支剧情；
- 不把虚构小剧场宣传成真实历史遗址或特定流派复原。

## 11. 文化来源与创意改编边界

- 神话母题主要依据 [`《山海经·海外北经》`](https://zh.wikisource.org/zh-hans/%E5%B1%B1%E6%B5%B7%E7%B6%93/%E6%B5%B7%E5%A4%96%E5%8C%97%E7%B6%93) 中逐日、渴饮、道渴而死与弃杖化为邓林的叙事，并参照 [`《山海经·大荒北经》`](https://ctext.org/shan-hai-jing/da-huang-bei-jing/zhs) 中追逐日影的异文；
- 皮影媒介结构参考 [联合国教科文组织“中国皮影戏”资料](https://ich.unesco.org/en/RL/chinese-shadow-puppetry-00421?RL=00421)：纸或皮革人物、操杆、背光的半透明幕布，以及音乐和演唱共同构成表演；
- 对外统一表述为“基于《山海经》夸父逐日意象的创意改编”，不宣称考古复原、历史原貌或特定流派皮影的精确复刻；
- 项目文档与参赛材料需记录神话文本、美术纹样和皮影参考的具体来源，区分公共领域文本、作者创作设计与第三方素材；
- 文化说明服务玩家理解，不做百科式长文本；核心信息必须由灯、偶、影与演出动作表达；
- 若最终造型借鉴特定地区皮影，应注明地域、参考出处与改编内容，并由作者保留视觉依据、选材与适配过程稿；
- “杖落成林”作为演出意象使用，具体视觉呈现允许艺术化，但不得把团队虚构细节包装为原典事实。

### 11.1 文化元素到玩法的转译

| 文化元素 | 游戏中的机制转译 | 玩家可见结果 | 创意边界 |
|---|---|---|---|
| 逐日 | 玩家移动“日”的光源，并调整夸父与光的空间关系 | 幕布上形成由远及近的追逐关系 | 原典没有“解谜”结构；三段互动是作者创作编排 |
| 夸父 | 同一个核心皮影通过位置、朝向和少量预设姿态逐步接近日轮 | 奔跑、伸手、持杖/落杖的轮廓递进 | 不宣称造型是某朝代或某流派的历史标准形象 |
| 弃杖化林 | 玩家完成最终持杖/落杖影形后，从手杖落点生长林影 | 高潮由最终操作直接展开，而非播放无关片段 | “光色恢复、戏台苏醒”等为艺术化新增内容 |
| 背光幕布 | 主灯、幕布和皮影的真实空间关系既是画面也是玩法 | 玩家同时理解幕后实体和幕上影像 | 不把普通投影贴图冒充实时影子 |
| 操杆与关节 | 皮影资产保留杆、分件或关节逻辑，但交互收敛为预设姿态 | 玩家能看出偶是被操纵的表演对象 | 为稳定操作而简化传统表演技巧，需在说明中承认 |
| 音乐与表演 | 每完成一段，木击、鼓点、呼吸、环境声和音乐层逐步恢复 | 戏台从沉寂到完整演出 | 不声称使用了某地域传统唱腔，除非真实考证并获授权 |

### 11.2 文化创意的核心表达

本项目不以“用了皮影”和“用了《山海经》”作为创新结论。文化创意必须同时满足：

1. 玩家操作的对象就是文化隐喻中的“日”和“夸父”；
2. 玩家完成的动作就是“引日、逐光、杖落成林”，而不是与故事无关的通用开关；
3. 皮影的灯—偶—幕关系决定视觉和交互，而不是只提供一层国风外观；
4. 高潮从玩家最后形成的影子继续生长，证明叙事回报来自玩家行为；
5. 幕后和幕上至少被同一镜头共同揭示一次，兼顾文化解释、实时性证明和展示记忆点。

### 11.3 与相邻作品比较后的定位

- 相比以皮影为美术风格的作品，本项目让皮影结构成为玩法；
- 相比 `Shadowmatic` 式轮廓匹配，本项目不让玩家猜任意物体，而让三次影形连续完成同一神话；
- 相比 `Projection: First Light` 式光影平台玩法，本项目不做横版冒险，而呈现一个可从幕后操作到幕上演出的中国皮影戏台；
- 相比泛化《山海经》场景漫游，本项目锁定夸父与日、手杖与林，以短流程换取清楚的动作—意象—回报关系；
- 相比皮影 AI 生成或数字档案项目，本项目的重点是 UE 实时交互、稳定工程链路和现场可玩的叙事完成度。

因此，对外可主张的是“特定文化动作、媒介结构和实时交互的组合创新”，不能主张“首次数字皮影”“首创影子解谜”或“历史复原”。完整对比与优劣分析见 [`COMPETITION_BENCHMARK.md`](COMPETITION_BENCHMARK.md)。

## 12. 失败、重置与结束

本 Demo 无死亡与传统 Game Over。

- 当前互动可局部重置；
- 流程异常时可从暂停菜单重新开始 Demo；
- 成功状态一旦记录，不因玩家走开而撤销；
- 结束后提供“重新体验”和“退出”即可，不增加关卡选择。

## 13. 验收问题

每次迭代都用以下问题判断是否保留：

1. 玩家是否能直接看见操作如何改变影子？
2. 这个内容是否服务三次互动或高潮？
3. 它是否复用已验证系统？
4. 如果视觉阴影发生轻微差异，逻辑是否仍稳定？
5. 它是否让 5–8 分钟节奏更清楚？
6. 文化母题是否通过玩家操作成立，而不是只靠标题、字幕或装饰说明？
7. 评审是否能在 60 秒内看懂“灯是太阳、影是夸父、操作推动神话复演”？
8. 盲测者是否认为“落杖造成成林”，而不是两个相邻但无关的事件？
9. 核心操作镜头是否同时解释幕后原因和幕上结果？
10. 静音、降低画质或关闭次要特效后，谜题是否仍可理解并完成？
11. 场景是否像一座完整小剧场，而不是黑盒中的灯、偶和幕布？
12. 玩家是否能在不读长文本的情况下理解“未完逐日—自己负责复演”？
13. 环境扩展是否仍属于同一主地图，并且没有增加环境任务或无意义步行？

若多数答案为“否”，移出当前竞赛版本。
