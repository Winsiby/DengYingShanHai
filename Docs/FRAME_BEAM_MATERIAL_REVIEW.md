## 3. 新增独立数据复算：不只比较UV边界

直接解析原始亭FBX、派生梁和派生柱的实际indexed per-corner UV/Normal；只提取旧独立解析器的四个纯数据函数，不执行旧提取/导入/主程序。梁10面/28个离线fan三角，柱98面/252个离线fan三角，覆盖所有角点。两个Geometry（含UV/Normal）逐属性字节与原件相同，七个输入SHA前后相同；原三张图实际2048×2048。

以原统一灰盒缩放0.39290377163557627、2K源纹理计算每个面的UV物理Jacobian。下表是**源texel/m**，不是实际木纹频率、实际mip、正式物理木纹尺寸或目标画质标准。

| 面组 | 沿构件长向 | 横向 | 说明 |
|---|---:|---:|---|
| 梁主要侧面/底面 | 约198.14–198.15 | 约198.15 | 接近等密度 |
| 梁顶面 | 140.114 | 198.152 | 主方向密度比约1.414，不能与侧面同等看待 |
| 梁斜端部分面 | 最低99.013 | 约198.152 | 部分面约2倍各向异性，轴向投影映射U/V并非一律相同 |
| 柱身木槽0 | 259.602 | 546.787–773.274 | 横向约纵向2.106–2.979倍；柱本身也不是已确认的正确基准 |
| 柱顶面 | 主方向259.596–259.609 | 主方向近一致 | 不证明该纹理具备木材端纹，顶面外观仍待单独验证 |

普通全局平铺会同时放大所有方向，因此不会改变各向异性比值。即便仅将梁侧轴向198.152乘1.310115对齐柱轴259.602，梁顶轴也只有183.566；顶面需约1.852784才能对齐该轴。两者不相等，且柱横向546.787–773.274仍未解决。**1.310115不能作为完整修复方案，也不能把柱259.602称为正式标准。**

梁没有独立垂直平端盖，六面属于斜端/折面。源 polygon3/5 的轴向切向UV映射接近U，其余斜面更接近V；全件一次90°旋转不能证明所有斜面的纹向一致。自动UV chart seam本身不等于可见缺陷，不据此直接判模型不可用。

源每角法线与几何法线最大偏差：梁约0.00006782°、柱约0.00003502°；没有反向/垂直法线、UV或几何零面积、fan反绕向。此检查只排除这些源数组缺陷，**不认证UE实际三角拆分、导入切线、NormalDX高光或暗接触根因**。

完整独立数据位于本Audit的 `Independent/INDEPENDENT_SOURCE_UV_NORMALS.json` 和MD，保留逐面/角/三角形、输入与算法记录。

## 4. 材质、灯光与镜头架构边界

当前依旧 `SM_DY_FrameBeam_Source → MI_DY_FramePost_Wood → M_DY_FramePost_Master → 三张Dark Wood纹理`。Surface/Opaque/DefaultLit/单面、Deferred/r.Substrate=0和Texture导入设置沿用旧准入证据，不冒充本轮重新检验全部材质图。

既有图的评估顺序：UV0 → QuarterTurn端点选择 `(V,1-U)` → 三张PBR采样 → Diffuse到BaseColor、ARM的R/G/B到AO/Roughness/Metallic → NormalDX逆基底 `(-Ny,Nx,Nz)` → Normal；Specular=.5。Diffuse sRGB、ARM线性Masks、NormalDX线性NormalMap仍为旧合同。父材质没有Tiling参数；仅新建MI并不能添加这种能力。

本轮参数变更只涉及诊断视口位置/旋转，单位cm/degree；保持FOV90，不加lag/shake/postprocess/Sequencer、无最终POV抢占。近/中/远仅增加相机至同目标距离，观察细节随屏幕覆盖下降；拍完恢复原视口与GameView。主体Movable投影灯、两盏环境灯、曝光、源大小、阴影等不调节，不用增加孤立亮度或Emissive掩盖暗面。

不增加Master、MI、Material Function、Layers、静态开关、透明叠层、WPO、RVT、MPC、纹理或运行时参数更新。没有测GPU、显存、Material Editor compiled stats、Shader Complexity或Lumen/VSM诊断；不据此宣称渲染性能/材质/光照已验收。若今后需要这些诊断，应在独立工具模式下标注并恢复，不带入主玩法。

材料技能使“UV密度、纵横拉伸、纹向和材质族”分开评估；灯光技能使“暗”不被直接归为法线错误或用补光代替诊断；镜头技能区分编辑器取景与玩家POV。它们没有造成本轮产品材质或光照变化。
