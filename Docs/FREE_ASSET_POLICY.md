# 《灯影山海》免费与开源资产政策

> 状态：项目硬约束  
> 适用范围：比赛提交版、现场演示版、录屏版、项目源文件及其依赖  
> 最后更新：2026-10-01

## 1. 结论

《灯影山海》不采购任何付费模型、材质、纹理、音频、字体、动画、插件、代码、模板或生成服务。最终作品只使用以下三类内容：

1. 许可清晰的开源或公共领域资产；
2. 允许免费下载，并明确授权在游戏项目中使用的免费资产；
3. 作者自行制作、拍摄、录制或在合法工具中生成，且权利归属和使用条件明确的资产。

“可以免费查看”“可以免费下载”“GitHub 仓库公开”都不等于可以复用。没有许可证、许可证不覆盖修改/发布、来源不明或无法留存授权证据的资源，一律不进入正式版本。

## 2. 许可优先级

| 优先级 | 许可类型 | 项目处理方式 |
|---|---|---|
| P0 | CC0 / Public Domain | 首选；仍登记作者、来源页、下载日期和许可快照 |
| P1 | MIT / BSD / Apache-2.0 / zlib 等宽松开源许可 | 可用于代码、工具或适用资产；保留许可证及署名要求 |
| P2 | CC BY | 仅在署名链清晰，且能在作品说明、片尾或许可清单中完整履行时采用 |
| P3 | 免费专有许可、Fab 免费条目等 | 逐条审查；确认允许比赛展示、录屏、打包分发和必要修改后才可采用 |
| 禁止 | 无许可、仅供个人使用、禁止修改/发布、来源转载不明、付费资产 | 不下载到正式资产库，不作为兜底方案 |

补充规则：

- “开源”主要适用于代码；模型、纹理、音频等必须核对相应内容许可。
- GPL/LGPL 代码或插件需单独评估分发义务，非必要不引入当前竞赛版本。
- CC BY-NC、仅非商业使用或用途模糊的资源原则上不采用，避免比赛宣传、平台展示或后续成果转化发生冲突。
- AI 生成资产不能自动视为开源；必须记录工具、服务条款、输入来源、生成日期和人工修改过程。

## 3. 免费资产的质量策略

免费资产只提供几何或纹理基础，不直接决定最终美术风格。为了避免“廉价感”，正式场景执行以下规则：

1. 固定艺术方向：幕外为克制写实的当代传统院落演出空间，幕上为平面化的山海影画。
2. 统一重做材质实例：木、漆、布、纸/皮、青铜、石材和污渍贴花由项目主材质控制，不保留不同资源包互相冲突的默认观感。
3. 只选少量高质量骨架资产：一个主戏台/亭体、一个主树、少量中景树、灯笼和桌凳；不用“大而全”的低模包填满画面。
4. 通过固定镜头、遮挡、景深、雾、色温和声场控制，把精度集中在玩家可见区域。
5. 风格不合的免费资源即使技术上可用，也只进入 `Content/DengYingShanHai/Dev/` 做灰盒，不进入正式镜头。
6. 夸父皮影不直接套用所谓“现成夸父模型”；以文献和公共领域历史图像为依据，使用免费工具完成项目专属的 2.5D 分片、骨骼和纹样适配。

## 5. 明确排除

- 任何需要付款、订阅、积分购买或商业授权升级的资产。
- 历史文档中作为质量兜底提到的付费 Fab 场景包；从现在起不再是项目候选。
- 没有 LICENSE 的 GitHub 项目中的代码、`.uasset`、模型、纹理和音频。
- `Shadow_puppet_Unreal` 仓库中的代码和资产：仅研究公开文档、目录结构和制作思路，不复制内容。
- 来源不明的网盘整理包、从商业游戏提取的模型、二次转载但找不到原作者许可的资源。
- 仅标注“free download”却没有明确使用许可的资源。
- 以大量通用低模中国风套件直接拼正式场景的方案；这类内容最多用于灰盒或不可见远景。

## 6. 每项资产的准入记录

每项进入正式版本的外部资产必须在 `Docs/LICENSES.md` 或资产台账中记录：

- 资产名称与内部资产路径；
- 原作者/发布者；
- 原始页面与直接来源；
- 许可证名称及版本；
- 下载日期；
- 许可页面或许可证文件的本地快照位置；
- 是否修改，以及修改内容；
- 使用镜头/关卡；
- 署名文本及展示位置；
- 负责人；
- Development 与 Shipping 打包验证结果。

无法完整填写上述信息的资产不得从 `Dev/` 移入正式目录。

## 7. 负责人

- 用户：唯一人类负责人，负责许可初审/终审、筛选、适配、导入、材质、构图、性能、打包、原始资源和第三方清单。
- Codex：按授权辅助查询、实现及核查，不替作者签署许可结论，不作为制作成员。
- 不得把未经登记的素材放入正式目录，不以作者不会建模为由使用无许可或付费资产。

## 8. 零付费路线的降级顺序

若免费资产达不到预期质量，按以下顺序降级，不转向购买：

1. 调整镜头与可见范围，减少不必要的完整建筑展示；
2. 对高质量 CC0 单体做模块化重组和统一材质；
3. 用平面剪影、雾、暗部和景深替代远景高精度几何；
4. 使用简单基础体配合高质量 CC0 材质制作不可交互建筑部分；
5. 缩减装饰数量，把精力集中到幕布、灯、夸父皮影和第三幕成林效果；
6. 若某个镜头仍无法达标，修改演出调度，不购买资产、不扩大场景。

该降级顺序不改变“一座戏台、三次互动、一个高潮结尾”的范围。
