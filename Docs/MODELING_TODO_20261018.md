# 《灯影山海》建模待办清单

日期：2026-10-18。依据当前资产清单、舞台美术接入记录和复演者/夸父交接整理。这里只列**建模与局部网格修订**，不列 C++、Blueprint、音频、UI 和打包任务。

## 先看结论

如果时间只够做 5 件，按这个顺序：

1. 夸父左手握杖轮廓 + 独立木杖最终版。
2. 三组目标影形/纹样（引日、逐光、杖落成林）。
3. 完整幕框：左柱、顶梁、幕布上卷轴/下配重杆，外加《逐日》题签。
4. 成林叶簇/枝形最终轮廓。
5. 入场短廊与台前台阶。

这 5 件直接决定“像不像一座影戏台”和“第三次互动能不能读懂”。其余是层次与氛围。

## P0：不做会直接影响核心体验

### M-01 夸父握杖手与最终木杖

- [ ] 修左手正/背交握轮廓，让手真正“包住”杖，而不是平片贴在杖前。
- [ ] 保持右手不强行握同一根杖；当前右手离杖约 60–67 cm，先不要改动作语义。
- [ ] 独立木杖最终版：保留现有 A/B 端点、约 3 cm 杖半径和握把缠绳；杖尖 A 端要清楚可辨。
- [ ] 三个姿态（StrideBack / StrideMid / Reach）都检查手、袖口、飘带与杖的穿插。
- [ ] 不新增 IK、不新增骨骼、不重写三套动画；只做局部网格和握把形状。

**交付**：改好的手片/袖口/杖网格，或一份新的 `SK_DY_Kuafu_...` 局部版本；保留 20 骨和 6 材质槽。

**验收**：1080p 正面和背面都能看出“手在握杖”；三姿态无穿手、穿袖、穿杖；杖尖在影子里不被身体吞掉。

### M-02 三组目标影形/纹样

- [ ] 引日启幕：日轮 + 头部弧线 + 开放缺口。
- [ ] 逐光成形：夸父奔跑/伸手的连续轮廓，至少能读出“人在追日”。
- [ ] 杖落成林：杖尖落点 + 向外生长的林纹/枝形母题，不提前泄露最终成林。
- [ ] 三组都做成可单独隐藏的线形/薄片几何或卡片，不填充遮挡真实影子。
- [ ] 与主幕坐标一致，线宽在 1920×1080 下清楚；不要做成调试 UI 方块。

**交付**：3 组目标影形资产，命名建议 `SM_DY_Target_P01/P02/P03` 或对应的 2D 卡片。

**验收**：叠在幕布上能看出“要往哪里调”，但不直接给出答案；三次互动都能单独开关。

### M-03 完整幕框与卷轴

- [ ] 顶部横梁/圈梁：补齐主幕上沿，避免现在只有单梁的“断框”感。
- [ ] 主幕上卷轴、下配重杆、两侧拉绳/挂钩。
- [ ] 柱头/梁托/简单角撑，数量克制，不要做完整古建大木作。
- [ ] 所有件不要侵入主幕 900×800 cm 投影开口。

**交付**：模块化 `SM_DY_Frame...` 若干件，复用现有木材材质；简单盒碰撞即可。

**验收**：从玩家 POV 看是一个完整戏台框，不是一根梁加一根柱；不挡主幕关键投影。

### M-03b 《逐日》题签

**交付**：`SM_DY_TitlePlaque` 或一张可替换的题签卡片。

### M-04 成林最终枝形/叶簇

## 统一交付规格

- 单位：厘米；Z 向上；建筑/道具底面在 Z=0。
- 朝向：角色面朝 +X 或按现有资产约定，导出前应用变换。
- FBX：一个资产一个文件，不带相机、灯光、空场景。
- 命名：静态网格 `SM_DY_...`，骨骼网格 `SK_DY_...`，材质 `M_`，实例 `MI_`。
- 场景基准：主幕开口按 900×800 cm；核心操作区 Y 约 ±470 cm；侧台翼外沿到 Y 约 ±849 cm。
- 碰撞：建筑/道具用简单盒；远景卡片和装饰不碰撞。
- 材质：优先复用现有木材/纸/布/铜实例；新贴图单套不超过 2K。
- 不新增：第二戏台、第二房间、开放世界、NPC、可收集物、付费资产。
