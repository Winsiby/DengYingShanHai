# 灯影山海美术提升建议（2026-10-25）

## 检查对象与结论

当前公开入口是Run167 Shipping。本轮复算主地图与原生EXE的SHA256，均与Run167身份一致。最新可用打包画面来自10月23日的run167/run167b连续帧；本轮没有新启动游戏，也没有修改模型、材质、地图、相机或玩法。三张关键原帧按原样复制到D盘，[证据与来源](D:/灯影山海/Saved/ArtReview-2026-10-25/Evidence.json)保存捕获时间和哈希。

角色轮廓、纹样、题签和动态演出已有基础；最有收益的下一轮是把主表演区域、灯影关系和UI层次整理清楚。现有影偶可继续使用，不需要以新增角色或场景来提高完成度。

须区分取样与玩家体验：本次打包图为既有审查/诊断取景，源码也提供DY_DEBUG_VIEW；没有核实这轮具体取样参数，因此不能从右墙遮挡推出正常玩家全程都被挡住。取景问题应先在正常操作与演出视角确认。后三幕的PerfUE取样属于编辑器辅助证据，不能作为Run167后三幕实机验收。

## 四幕角色的补充观察

[精卫取样](D:/灯影山海/Saved/Audit-2026-10-23-Performance/PerfUE-Act2.png)、[刑天取样](D:/灯影山海/Saved/Audit-2026-10-23-Performance/PerfUE-Act3.png)、[烛龙取样](D:/灯影山海/Saved/Audit-2026-10-23-Performance/PerfUE-Act4.png)能辨认翼羽、斧盾和人面蛇身，旧“角色未制作、刑天横躺、烛龙头小、翼杆过长”不再按当前缺陷处理。这些图属于较早编辑器取样：角色多在幕面下部，灯具体量突出，建议在后三幕当前包正常视角验证主体占比及动作轮廓，再决定是否放大。

可选的下一层提升：每幕仅补一种低对比的影画意象，如精卫水纹/石影、刑天盾纹节奏、烛龙日月明暗；仍在同一幕面表达，不增加场景或独立玩法。应在取景、主次解决之后再做。

## 本轮不宜直接下结论的项目

- 没有最新Run167外景正常行走整帧，旧编辑器图的锥山、树干截面只能列待复核，不能照旧认定当前仍需删除。
- 静态取样不能充分判断动画速度、缓入缓出、帧间抖动和剪影节奏；应看连续片段后再改动画。
- 项目配置为DX12、Lumen GI/反射、VSM且硬件光追关闭；本轮没有重新读取关卡曝光参数或采性能数据，未给全局增亮/降画质方案。
