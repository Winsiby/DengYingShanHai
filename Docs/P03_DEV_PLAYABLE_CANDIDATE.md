## 玩家可见结果与操作

1. 初始灯与偶保持地图原值，不会自动解题；顶部显示“杖落成林 · Dev候选”。
2. 对准灯或偶，E 操纵、A/D 调整、E 放开。移动和鼠标继续使用现有 Explore 模式。两项必须一起到位并保持；一项有效不能完成。
3. 原生成功后先提示影形已稳，**从本次真实成功姿态继续**下落手杖。保留旋转、缩放、灯偶根变换与幕上横向接触位置，不瞬移换构图。
4. A 端实际投影接触已确认地线后，才生成同一主灯下的真实枝形投影；先做完整网格边界和头身保护区预检，再逐步生长。
5. 完成后保持林影。原 HUD 的成功文案暂写“第三幕影形 · 成”，避免把逻辑 Resolve 当作成林已经完成；独立 Dev 文案区分落杖、生长、演出完成。
6. **R 仍是原有上下文行为**：当前还操纵某对象时，R 复位灯偶及本次谜题，旧身份失效后清除林枝并恢复脚本负责的手杖位移；不覆盖原生复位姿态。放开操纵后，Explore R 只复位玩家，不是整幕/整局重启。成功后放开对象不能保证再操纵已禁用对象，欲完整重试可关闭独立编辑器、重新打开此入口。
7. 不设置玩家等待或完成态的自动退出时间。停止 PIE 会清理临时对象，但现在保留该入口打开的编辑器；不要保存临时地图。完整重试请正常关闭这个测试编辑器、选择不保存，再双击入口。不要直接在已清理的地图里按普通 Play，期待自动重建候选。Python 执行提示可能仍显示，这是防止命令行 Python runner 自动退出编辑器的留存机制，不代表游戏仍在加载或继续执行表现回调。

没有输入锁或新镜头；PlayerController 仍是唯一 POV 所有者。镜头可按现有规则移动，自动检查不代替“能看清幕后原因与幕上结果”的人工验收。

## 架构、寿命和依赖

| 对象 | 权限 / 所有权 | 寿命与通信 |
|---|---|---|
| 既有 Puzzle Director | 唯一谜题事实与 15 Hz 保持判定 | 当前 PIE，会话内 Definition 指向 transient-package 候选；结束前恢复 |
| 既有 Stage Presentation | 当前 Resolve、真实接触与 Forest 授权 | 通过现有公开快照/token 接口读取；不制造成功事实 |
| 已保存 Forest BP / 原生 Actor | authoring / 真实枝组件 | 仅临时实例；原生 Reset/Clear/EndPlay 释放；不改 CDO 或资产 |
| 新 Play 脚本 | Editor-only 临时演出适配，不判通关 | 单个 Slate callback 显式引用已知 Actor；2/6 秒世界时间只输出表现进度 |
| 既有 HUD + 临时文本 | 表现，不拥有输入和判定 | 一次公开 Widget 查询，再按已核实名称查 native 子对象；不轮询找 Widget |
| 既有 PlayerController / Pawn | 原输入上下文与 POV | E/A/D/R 语义不变，不注入、不绑新键、不设 view target |
| 独立 Verify 脚本 | 诊断，不是玩家完成 | 调已有参数 setter、真实时间等待；E/R 检查只调同一语义接口，不冒充物理按键 |

脚本不访问 HUD 私有 View，不修改 C++ 来扩接口，不复制 C++ 判定逻辑，不通过每帧世界扫描发现对象。每帧只有当前显式会话检查与表现进度。第三幕组合仍复用前两幕已学连续控制量，体现“综合运用”；这是可玩的因果灰盒，不是高质量正式剧场或文化资产成品。

**打包边界：** Python Slate 适配只在 Editor 工作，不能出现在独立游戏包中。验证候选后，正式 Blueprint/Sequencer 演出接入仍须按批准范围单独实现并验收。当前没有 Build/Cook/新包，不借用旧包 11/0 或旧 Editor 70/0 声称本轮通过。
