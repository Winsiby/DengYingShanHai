这说明可做局部接缝比较，不说明已经获得牢靠承托：接合面积有限，源顶齐关系被改为柱顶接面，端头倒角、遮挡、近景法线和视觉合理性必须真实看图。不能以这些数字推断位于主灯光锥外、所有 GI/反射零影响、玩家 POV 无遮挡或完整流程通过。

**当前没有左柱。**本方案不把未支撑的左端包装成成品幕框。完整框需要另列左右支撑/对称长度选择；不得自动补左柱、移动右柱、改变幕布、拉伸梁截面或隐去旧灰盒。8m 柱和约 10m 梁仍是大灰盒开发比较，不是正式建筑尺度。

## 5. 木纹方向正确，不等于密度一致

保持现有有界木材父材质与常量实例：Surface/Opaque/DefaultLit/单面、r.Substrate=0。材质顺序为 UV0→QuarterTurn1 `(V,1-U)`→三张 PBR 同坐标采样；NormalDX 使用 `(-Ny,Nx,Nz)` 逆基底。柱身 64 条纵向边、梁 8 条纯长轴边均沿原 UV V，因此方向已有依据。

轴向采样频率按实际长边计算，不能把全件 bounds 长度当作每条 UV 边的长度：

```text
q = 100 * abs(DeltaV) / (sourceEdgeLengthCm * uniformScale)
equivalentSourceTexelsPerMetre = 2048 * q
```

| 面与候选 | 等效源 texel/m（约） | 相对当前柱身 |
|---|---:|---:|
| 当前 8m 柱身 | 259.60 | 100%（不是已批准目标） |
| 同柱 scale 的梁源 +Y 顶面 | 140.11 | 53.97% |
| 同柱 scale 的梁两侧／底面 | 198.15 | 76.33% |
| 全梁 bounds 长 1080cm，顶面 | 134.09 | 51.65% |
| 全梁 bounds 长 1080cm，两侧／底面 | 189.63 | 73.05% |

两组源梁密度约差 √2，整个梁统一乘一个 UV 倍率也不能把所有面同时匹配。数字只表示 2K 原图采样覆盖，不代表实际流送 mip、屏幕像素密度、木纹毫米尺度、细节清晰度或审美合格。

现有父材质只有 UVQuarterTurn 与三张纹理参数，**没有 Tiling 参数**。不能仅新建 MI 后设置不存在的参数，更不能覆盖共享旧 MI/Master。先冻结旧实例作真实近中远对照；只有实测出现明显割裂，才提出独立 Dev 有界父材质副本及必要轴向/横向倍率，不引入万能世界坐标材质、动态 MI、WPO、MPC、透明、Substrate或新插件。
