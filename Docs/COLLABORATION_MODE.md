# 单人制作与当前 AI 辅助模式

更新：2026-10-09。用户明确纠正项目由自己一人完成；后续“你来解决”“你来完成接下来的任务”已经将当前工具执行改为 Codex 直接辅助。2026-10-06 的 WorkBuddy 实施模式保留为历史，不覆盖当前要求。

## 唯一责任人

- 用户：唯一人类作者与项目负责人，负责技术、美术、声音、动画、视频、许可与最终提交的整体决策和审查；真人体验和新增权衡由用户确认。
- Codex：当前批准范围内的实现、资源研究、集成、构建、独立核查及文档辅助；不冒充人类制作成员或替用户签收体验。
- WorkBuddy：只在用户再次明确指定的任务中辅助；未获该轮发送许可不自行向其交付资料。输入限制规则保留。

## 执行循环

1. Codex 核对最新需求与本机状态，保留基线、文件白名单和回退说明。
2. 当前由 Codex 在明确范围内直接实施，不依赖未存在的制作人员。若该轮改用 WorkBuddy，短摘要尽量控制在约 150–250 字并附本地文件；实际输入上限未知，不把它称为固定 250 字。
3. 先执行狭窄阶段；核查差异与原始证据后再继续。超出白名单、参数变化或方案权衡须停下交用户决定。
4. 长报告放本地审计文件，聊天只报阶段摘要、结果和文件位置。
5. 核对原始日志、测试失败数、完整命令、包身份、保护文件哈希和截图；自动结果与真实键鼠体验分别登记。
6. 构建成功、自动答案诊断和真实键鼠体验分别记录；通过后交付绝对路径，并提示 CMD 在资源管理器双击，聊天链接可能只显示代码。

## 交互与保护

- 保持已有工作空间、权限模式与模型，不自行更换或放宽权限。
- 输入前观察正确输入框；使用短摘要 + 本地文件，不能重复发送状态不明的同一任务。
- Computer Use 不可用或被用户打断时停止输入；不换成隐蔽的桌面自动化，不声称已发送。
- 若用户指定 WorkBuddy 实施，该轮不可用时先报告，不自行更换执行者；当前 Codex 直接实施来自用户后续授权。
- 不凭 WorkBuddy 报告将失败改成通过，不降低断言，不伪造人工验收，不清理用户旧改动或测试失败证据。
- 本项目相关任务信息仅按用户批准的任务发送 WorkBuddy；不发送密钥、账号、无关个人信息或其他项目数据。
