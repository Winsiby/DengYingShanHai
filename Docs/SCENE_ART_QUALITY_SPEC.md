# 《灯影山海》场景美术与资产质量规范

> 目标：在不扩大“一座戏台、三次互动、一个高潮结尾”的范围下，使画面达到参赛展示需要的完成度，避免低模包、默认模板和多套免费素材直接拼接形成的“廉价感”。

## 1. 统一美术方向

采用“双层视觉语言”：

```text
幕外真实剧场：克制的写实 PBR、可触摸的木/布/纸/铜/石
幕上山海影画：平面化、剪影化、留白、纹样与节奏优先
```

不做完全写实的古代城市，也不做全场景卡通低模。玩家站在一座经过岁月使用的院落戏台中，能看到漆木台口、布幕纤维、灯具铜锈、石板潮痕和幕后操纵杆；幕布上的夸父、日轮、河泽与桃林则保持皮影和剪纸的图形语言。

高质量的来源是两层风格之间有明确对照，而不是增加更多资产。

### 1.1 文化时空边界

幕外戏台定位为“当代创意改编中的传统院落演出空间”，不是夸父时代、先秦建筑或某一非遗流派的考古复原。幕上故事以《山海经》夸父意象为母题，幕外则使用观众熟悉的中国木构戏台和皮影演出语汇承载表演。

因此：

- 可使用后世成熟的柱梁、瓦顶、栏杆、帷幔和灯笼，但必须克制，不标注为先秦原貌；
- 不使用明显的佛寺、宫殿、皇家金瓦、日式鸟居、神社灯笼或混合“泛亚洲”装饰；
- 斗拱、雀替等构件只作为戏台视觉语言，数量与复杂度服从镜头，不做建筑复原展示；
- 夸父、日轮、河泽、手杖化林等神话内容只在幕上影画和演出反馈中展开；
- 文档、答辩与字幕统一使用“创意改编”“传统媒介转译”“实时光影交互”，不使用“历史复原”“文物复刻”。

## 2. 场景构图

### 2.1 空间分层

| 层级 | 内容 | 画面任务 | 资产策略 |
|---|---|---|---|
| 前景 | 石板、矮栏、少量观演坐具、落叶 | 提供尺度和镜头遮挡 | 高质量材质，低数量 |
| 中景核心 | 戏台、台口、幕布、灯具、夸父皮影 | 承载全部玩法和视觉焦点 | 项目定制 + 精选 Hero 构件 |
| 幕后空间 | 木架、皮影架、操纵杆、灯罩、线缆/绳结 | 强化“戏是如何被演出来的” | 真实结构，局部精细 |
| 远景 | 院墙、屋檐剪影、树冠、雾、月色/夜空 | 扩大场景感，不与戏台抢视线 | 简化几何、实例化、雾中剪影 |

### 2.2 镜头阅读顺序

第一眼：亮起的幕布与日轮。  
第二眼：玩家可操纵的灯和夸父。  
第三眼：幕后木架、皮影部件和周围院落。  
第四眼：远景屋檐、树冠和雾。

任何高对比灯笼、金色装饰、鲜艳植被如果抢在幕布之前被看到，应降低亮度、饱和度或从镜头中移除。

## 3. 颜色与材质

### 3.1 主色比例

- 60%：深褐、黑褐、灰石、旧木；
- 25%：幕布暖白、纸张米白、雾蓝；
- 10%：朱漆、暗红织物；
- 5%：日轮金、灯火橙、桃林高潮色。

红色与金色只能做节奏标记。全场大面积正红、亮金会使画面像节庆素材包，削弱古朴和神话感。

### 3.2 项目主材质库

正式场景中的外部模型必须替换或接入以下主材质体系：

- `M_DY_Wood_Master`：木色、漆层、磨损、灰尘、湿度；
- `M_DY_Lacquer_Master`：朱漆/黑漆、边缘磨损、低频色差；
- `M_DY_Cloth_Master`：幕布、帷幔、纤维法线、透光控制；
- `M_DY_PaperLeather_Master`：皮影表面、半透明色、孔洞 Mask；
- `M_DY_Bronze_Master`：灯具、锣、挂件的氧化和指痕；
- `M_DY_Stone_Master`：地面、台阶、院墙基座的潮湿和苔痕；
- `M_DY_Decal_Master`：尘、渗水、脚印、磨损，不覆盖核心纹样。

每个外部包自带的独立材质只能用于导入对照，不能直接散落在最终关卡中。

### 3.3 纹理预算

- 幕布、台口、主灯、夸父：单件 2K；只有镜头确认需要时使用 4K；
- 中景柱梁、屏风、茶桌：2K；
- 远景墙面、树木、石块：1K–2K；
- Mask、ORM 尽量通道打包；
- 不把来源提供的 8K 纹理原样全部导入；
- 同类木构件保持统一 texel density；
- 正式资产不得使用明显压缩块、拉伸 UV 或纯色默认材质。

## 4. 灯光设计

### 4.1 三层灯光

1. **皮影主灯**：唯一需要最高阴影精度的动态光，直接服务玩法；
2. **戏台实用灯**：低强度暖光，解释台口、灯笼和幕后结构；
3. **院落环境光**：冷色天空/月色与轻雾，分离屋檐和树冠。

建议从以下区间开始调试，而不是当成固定答案：

- 主灯色温约 2200–3200 K；
- 环境/月色约 6500–9000 K；
- 幕布高光不得剪切成纯白；
- 自动曝光在正式演出中锁定或限制到很窄范围；
- 只有主灯和极少数必要灯开启高质量动态阴影；
- 装饰灯优先使用无阴影灯、Emissive 或烘焙感表现；
- 体积雾只用于建立层次，不能让幕布阴影发灰。

### 4.2 质量验收

- 玩家移动灯源时，影子边缘变化连续；
- 角色关节之间没有因阴影偏移产生错误断裂；
- 幕布正面、侧面和幕后镜头都能读出材质厚度；
- 暗部仍保留木架和操纵杆轮廓；
- 关闭字幕后，观众仍能看懂当前视觉焦点；
- 录屏压缩后不出现大面积黑块、Banding 或闪烁 Mask。

### 5.2 只能用于灰盒或远景的候选

| 资源 | 原因 | 结论 |
|---|---|---|
| Kenney / KayKit 低模包 | 轮廓清楚、性能低，但材质与比赛主视觉过于简化 | `Dev/` 灰盒或极远景 |
| Quaternius 通用自然包 | 质量较完整，但风格偏通用卡通；与写实剧场混用容易割裂 | 只取不可见细节或远景，必须统一材质 |
| 3DAssets.dev Imperial China pack | CC0、组合完整，但页面标明使用 AI 工具，尺寸很小、风格化且文化细节可能失真 | 灰盒构图参考，不进入最终近景 |
| Sketchfab 1.4K tris Chinese Lantern | CC BY、结构简单，适合占位但近景质感不足 | Secondary/占位，不做 Hero |

### 5.3 排除项

- 未提供许可证的 GitHub 仓库资产；
- Meshy、文本生成 3D 等未经人工文化与拓扑复核的 AI 资产；
- 免费但只允许非商用、研究或个人用途的模型；
- 把“Japanese/Asian/Oriental”标签直接当作中国传统建筑依据的资源；
- 需要多个未知插件、自动改写 Project Settings 或强制启用高开销系统的整场景包；
- 自带完整花园、寺院、宫殿却与一座民间戏台叙事无关的豪华场景。

### 5.4 零付费质量降级方案

[Traditional Chinese Style Park](https://www.fab.com/listings/c123c1af-a0ab-4855-8deb-e9aa1a696a13) 是目前较贴合的高质量 Fab 候选：UE 5.3、模块化门窗栏杆柱梁、斗拱和雀替，评分与演示资料较完整。它仍不是开放资产，而且包含寺庙、桥、农田等大量本项目不需要的内容。

如果免费亭台经过材质重制后仍达不到镜头要求，不转向购买。依次缩小建筑可见范围、调整镜头高度和遮挡、重组少量 CC0 柱梁/栏杆/门窗、用统一材质提高整体性，并把预算集中到幕布、灯、夸父和成林高潮。仍不合格时缩减装饰，不扩建场景。

## 6. 自然环境与“杖落成林”

### 6.1 正式画面不直接寻找整套桃树包

高质量桃林的识别主要来自：枝干轮廓、花/叶色、节奏化生长和声音，而不是植物学级写实模型。免费库中没有发现许可证、质量和性能都足够稳定的整套写实桃树资产，因此采用组合方案：

1. 从 Poly Haven 或许可清晰的高质量库选一套 broadleaf 树干/枝条；
2. 主树使用项目自己的枝干生成方向和剪纸叶簇；
3. 通过材质实例把叶片控制在暗红、桃粉、墨绿的小范围；
4. Hero 树展示生长过程；背景树使用 HISM 和简化剪影；
5. 花瓣只在高潮镜头中使用少量 Niagara，不持续全场飘落。

### 6.2 环境资产上限

- Hero 主树：1；
- 中景树变体：2–3；
- 背景剪影变体：3–5；
- 岩石/台阶变体：3–5；
- 地面材质：1 套主石板 + 1 套泥土/落叶混合；
- 可见灯笼：2–4；
- 屏风、桌、凳等叙事道具：每类不超过 1–2 件。

限制数量能让团队有时间统一材质、摆放和光照，也能减少“素材商店展示间”观感。

## 7. 音频开放资源候选

本轮已找到可作为原始母素材的 CC0 录音：

- [Footsteps Wooden Floor](https://freesound.org/people/spenceomatic/sounds/119766/)：48 kHz、24-bit、木地板脚步；
- [Footsteps Leaves](https://freesound.org/people/spenceomatic/sounds/119765/)：48 kHz、24-bit、落叶脚步；
- [Leafs in Wind](https://freesound.org/people/Sadiquecat/sounds/827366/)：192 kHz、24-bit、枝叶风声；
- [Walking on foliage](https://freesound.org/people/Dominik_W/sounds/398685/)：44.1 kHz、24-bit、林地脚步。

这些素材只代表许可和技术参数初筛通过，尚未完成试听。正式采用前必须检查底噪、鸟声、口播、空间混响和循环接缝，并进行剪辑、降噪、分层与响度统一。

锣鼓点和吟唱仍未找到文化语境、表演质量和许可都足够可信的免费统一来源。它们是演出身份的核心声音，不应使用“Chinese gong”搜索得到的任意音效代替。优先级为：优先研究明确授权的免费传统音乐素材与经核验的 CC0/CC BY 单击、鼓点；作者自愿录制可作为候选，不依赖外部表演者或付费委托。未经确认不导入。

## 8. 消除“廉价感”的具体检查表

### 8.1 必须做

- 删除最终关卡里的 Mannequin、Starter Content 示范物和网格测试材质；
- 外部模型统一命名、单位、枢轴、碰撞和材质；
- 每个外部资产至少有一处项目化修改：材质、色彩、轮廓、结构裁剪或叙事用途；
- 木、漆、布、石、铜的粗糙度范围统一；
- 近景接缝用压条、榫接、绳结或合理遮挡解释；
- 重复资产改变尺度、朝向和局部材质，但不随机改变整体风格；
- 用光引导视线，而不是给每件道具单独打亮；
- 在 1080p 录屏压缩后复查阴影、暗部和字幕；
- 保存灰盒、材质替换、灯光对比和性能截图作为过程证据。

### 8.2 禁止

- 同镜头混合写实 PBR、手绘卡通和无贴图低模；
- 为显得“丰富”摆满灯笼、桌椅、陶罐和花草；
- 直接使用资产包 Demo Level；
- 依靠 Bloom、体积雾、景深掩盖低质量模型；
- 全场纯黑导致层次丢失，或全场红金导致节庆舞台化；
- 把现代 AI 生成“东方风”纹样当作文物或历史依据；
- 在核心幕布附近使用高频树叶、栅格或图案造成阴影噪声。

## 9. 资产入场流程

```text
来源和许可审计
  → 下载到隔离目录
  → 保存许可/版本/截图
  → Dev/AssetAudit 导入
  → 比例、UV、法线、材质、碰撞、阴影检查
  → 替换为项目 Master Material
  → 固定镜头截图对比
  → GPU/内存/打包验证
  → 批准后迁移到正式 Content 目录
```

任何资产只要在许可、文化适配、风格统一、镜头贡献和性能五项中有一项失败，就不进入正式关卡。

## 10. 负责人和验收

项目负责人：

- 资产技术审计、导入、主材质、灯光、阴影、Nanite/LOD、实例化、性能、打包；
- 建立固定的 `LV_ArtReview` 和 `LV_ShadowLab`；
- 维护许可证与版本记录。

同一作者的视觉与媒体任务：

- 夸父、戏台、纹样和道具的文化与视觉审核；
- 对候选模型进行结构删减、贴图调整和颜色统一；
- 音频试听、剪辑和演示视频画面检查。

最终场景通过条件：

1. 固定的五个比赛镜头中没有可见占位物和默认模板资产；
2. 即使关闭后期 Bloom 和景深，构图与材质仍成立；
3. 所有外部资产能追溯到许可与来源；
4. 幕布永远是场景最高视觉优先级；
5. 第三次互动后的主树明显区别于通用树包；
6. Windows 打包版在目标电脑完成三轮无阻塞通关；
7. 评审截图放在一起时像同一作品，而不是多个资产包的展示图。
