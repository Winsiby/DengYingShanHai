## 5. Run1 失败与修正（失败证据保留）

| 阶段 | 事实 |
|---|---|
| Run1 | **PID 26456**；在**导入旧 ForestProjection 输出守卫**时**被拒绝**；**未进入 PIE、无截图、无 MotionFrame**；Editor 正常退出 |
| 最小根因 | 用直接子 Python 复现：现代 PowerShell 对方法 `SetEnvironmentVariable(name, $null)` 传出**空字符串**，而 `os.environ.get` 只在**键缺失**时选默认值 |
| 修正 | 改为 **Env Provider 删除**并按**原存在/缺失分支**恢复 |
| 守卫 | **旧守卫不放宽**；Run1 日志**保留** |

**另两次启动器干跑修正**（同样保留）：

- `Target` 在 PowerShell 7 中为**字符串而非数组**；
- **英文 alias 调用的根路径逻辑**；
- **未修改执行策略**。沙箱 Windows PowerShell 策略读取不同，实际桌面策略 `RemoteSigned`，
  原策略下干跑与 cmd 均通过。
