# 特性规格：V2.1 剧场世界重构（P0）

**Feature Branch**: `001-theater-world-v21`
**Created**: 2026-10-20
**Status**: Draft
**Input**: V2.1 总案《剧场世界重构_GitHub资源与DSH执行总案》第 0/1/2/5/6/9 节；约束来自 `.specify/memory/constitution.md` 与项目 `AGENTS.md`

## 背景与问题

当前正式图 `L_DY_Main` 是一个"狭小技术剧台"：只有幕布、主灯、皮影与少量台前灰盒，镜头拉远即露空。玩家从桌面启动器进入后直接落在第二幕，没有可操作的入口；剧场外没有任何真实空间，因此"影子改变世界"这一创意没有可被看见的对象。

本特性把舞台包进一座可被镜头完整读出的实体剧场，并在剧场外建立近中景真实世界，使"以灯为日、以影为夸父"的玩法第一次拥有空间与因果落点。

## 用户故事与验收

### 用户故事 1 - 从菜单进入剧场并完整演完三幕（P1）

玩家双击启动器 → 看到主菜单 → 点"开始游戏" → 镜头进入观众席、台上灯亮 → 按 E/A/D 完成 P01/P02/P03 → 成林 → 结束 → 可重演。

**为何最高优先级**：这是作品唯一的"可玩证明"。没有它，外景与美术在评审眼里只是静态场景。

**独立验证**：不依赖外景，只要主图能"菜单→三幕→重演"，即为可用 MVP。

**验收**
1. Given 冷启动游戏，When 主菜单出现并点"开始游戏"，Then 5 秒内进入第一幕且 HUD 显示"引日启幕"。
2. Given 处于任一幕，When 按 R，Then 当前幕重置且不退出游戏。
3. Given 完成 P03，When 林影生成结束，Then 出现结束提示并可按确认重演。
4. Given 重演，When 再次进入第一幕，Then 灯/偶/林影回到初始状态，无残影与残留节点。

### 用户故事 2 - 剧场外是一片真实可读的世界（P1）

镜头从台口向外推或转身，能看到剧场门洞外的院子、土路、树、房屋与远山层，而不是一张贴图。

**为何高优先级**：V2.1 的核心改向就是"剧场在世界里"，这是与上一版最直观的差别。

**独立验证**：在隔离图 `LV_DY_TheaterWorld_Preview` 中用固定机位拍三张透视，能读出"观众区→戏台→幕后"与"门→院→远山"两条纵深。

**验收**
1. Given 站在观众席后区，When 直视台口，Then 画面同时包含台口、幕布、主灯与至少两名观众席元素。
2. Given 走到剧场门口，When 向外看，Then 可见真实地面与至少 1 栋建筑、2 类植被、1 条路径；无穿帮黑边。
3. Given 任意机位，When 观察地平线，Then 远山与天空连续，无地面截断。

### 用户故事 3 - 成林之后，剧场外的世界回应玩家（P2）

P03 完成后，门外一棵枯树转为翠绿并起风，成为"影子影响真实世界"的唯一证据点。

**为何 P2 而非 P1**：它依赖故事 1 的成功事件；没有三幕就没有触发源。

**独立验证**：用调试按键在隔离图强制发送"P03 完成"事件，观察枯树状态切换与音效，不触碰谜题判定。

**验收**
1. Given 三幕未完成，When 观察门外枯树，Then 保持枯黄且无粒子。
2. Given P03 成功，When 演出结束 1 秒内，Then 枯树切换为绿叶并出现风动/鸟鸣，且切换只在成功路径发生。
3. Given 重演或重置，When 回到第一幕，Then 枯树回到枯黄初始态。

### 用户故事 4 - 菜单六项形成功能闭环（P2）

继续游戏（有暂停会话时）、演出篇章、游戏说明、设置、退出都真实可用，不再是灰条。

**验收**
1. Given 冷启动，When 查看"继续游戏"，Then 置灰且提示"暂无可继续的演出"。
2. Given 游戏中按 Esc 暂停后返回菜单，When 点"继续游戏"，Then 回到暂停前的幕与位置。
3. Given 打开"演出篇章"，When 浏览，Then 只列三幕真实题签 + 一行"后续篇章·制作中"，点击不跳关。
4. Given 打开"设置"，When 调整主音量与窗口模式，Then 立即生效；15 秒未确认自动回退。
5. Given 点"退出游戏"，Then 进程正常结束，无残留窗口。

### 用户故事 5 - 出一份能在别人机器上跑的包（P1）

**验收**
1. Given Shipping 包，When 双击启动器，Then 进入菜单并可完成三幕，全程无阻塞报错。
2. Given 打包目录，When 校验 SourceMapSHA256，Then 与当前 `L_DY_Main.umap` 一致。

## 功能需求

- **FR-001** 冷启动必须先进主菜单；`L_DY_Main` 不得再直接落在 P02 状态。
- **FR-002** "开始游戏"必须进入主图的 P01 起点，而不是测试图。
- **FR-003** 主菜单沿用现有 `DYDevEntryWidget` 版式，本轮零视觉改动。
- **FR-004** 继续游戏只恢复内存中的暂停会话，不写盘、不做假进度。
- **FR-005** 演出篇章只读展示三幕题签，不提供跳关。
- **FR-006** 设置至少提供主音量、窗口模式（全屏/窗口）、分辨率三项，改动 15 秒未确认回退。
- **FR-007** 剧场外壳、观众席、后台、入口大厅在隔离图 `Dev/WorldV2/Maps/LV_DY_TheaterWorld_Preview` 中先行搭建。
- **FR-008** 既有主灯、幕布、皮影、操杆、Guide、A 端接触点的 Transform 与引用链不得修改。
- **FR-009** 外景必须包含真实地面、路径、2–4 栋中式轮廓建筑、树木/石块、天空与分层远山。
- **FR-010** 外景远层可用低模/远景平面，但 A 圈 80m 内必须有碰撞与可站立地面。
- **FR-011** 成林反馈只订阅既有阶段完成事件；重演时回到初始态。
- **FR-012** 所有新增资产登记来源与许可；CC0 资源保留 LICENSE 原文。
- **FR-013** 打包产物需记录 SHA256，并提供启动器与校验文件。

## 非功能需求

- **NFR-001** Development 1080p 下主图帧率不低于 60 FPS（现有基线 130 FPS，允许外景带来下降）。
- **NFR-002** 冷启动到可操作不超过 60 秒（含着色器预热）。
- **NFR-003** 主菜单在 1280×720、1600×900、1920×1080 下文字不截断、按钮可点。
- **NFR-004** 全程静音可通关，声音只作增强。

## 关键实体

- **剧场外壳**：外墙、柱梁、屋顶、门洞、匾额（新增 Actor，包围既有舞台）。
- **观众区**：台阶、长凳、过道、灯笼（新增）。
- **外景 A/B/C 圈**：地面/路径/建筑/植被/远山（新增）。
- **世界反馈对象**：门外枯树（双状态材质或两套 Mesh 切换）。
- **菜单控制器**：`DYDevEntryWidget` + `DYDevEntryPlayerController`（已有，只加功能）。

## 成功判据

- **SC-001** 包内完整走完"菜单→P01→P02→P03→重演"，一次通过，无手动控制台干预。
- **SC-002** 至少一张截图能同时说明"剧场内部 + 大戏台 + 门外世界"。
- **SC-003** 枯树在成林前后各截一张，差异肉眼可辨。
- **SC-004** 四个 P1/P2 菜单项点击均有真实响应（无灰条假按钮）。
- **SC-005** 打包目录含 SHA256 校验文件，且与地图一致。
- **SC-006** 全部外部资产可在 `Docs/LICENSES.md` 中追溯。
