## 0. 一句话

一共 12 张图（A1–A6、B1–B3、C1–C3）。每张图要满足三件事：**能量出尺寸、能拆出 UV、能对上关节**。装饰可以夸张，但「不可变尺寸表」里的数字一个都不能动。

## 1. 通用约定（每张图都适用）

- **单位与朝向**：UE 厘米；世界 Z 向上；模型正面统一朝 **+X**（与角色前进方向、`SM_DY_LampBody` 一致）。
- **视图**：正立面 + 侧立面/侧剖 + 俯视或轴测，三选二以上；有断面的件必须给断面。
- **画幅**：长边 2048 px 以上，PNG；线稿、带色稿都收，但**标注必须能看清**（字号按最终 2048 宽可读）。
- **尺寸标注**：标「净尺寸」（不含装饰外挑）；装饰外挑、出挑、收分单独标。
- **材质分区**：每种材质用一色区分并写名字（木 / 纸 / 竹 / 漆 / 黄铜 / 布 / 石）。一色一区，方便我按区给材质和拆 UV。
- **贴图计划**：每件 2K、三张 —— BaseColor、NormalDX、ORM。UV 按「大面 / 小件」两级拆：大面独立 UV，小件（钉、环、绳结）共用一张 trim。
- **投影要求**：会挡光、会投影的件标「必须投影」；纯装饰且会造成脏影的标「不投影」。
- **风格锚点**：现有画面是国风影戏——朱红 `#A92D20`、暖金 `#D9A441`、宣纸 `#F1DFC0`、墨褐 `#2D2118`、青绿 `#3F6563`；皮影语言是「镂空 + 直线刀口 + 粗细对比」；外景是水墨三层（近实、中灰、远淡）。
- **交稿命名**：`A1_ShadowWindow_v01.png`、`C1_Jingwei_Ortho_v01.png`；同一张图的多个视角按 `_front` / `_side` / `_section` / `_detail` 后缀。
- **放哪**：`Assets/Sources/DengYingArt/Concept-20261021/`（我来建目录，你按编号放即可）。

## 3. 逐张说明

### A1 · 影窗幕面 + 幕框（最优先）

- **对应槽位**：`DEV_BackScreen`，Cube 50×900×800 @(950,0,424)，幕面 y±450、z24–824。当前挂的是引擎默认灰材质——整出戏的影子都投在这块默认面上，这是目前最刺眼的一处占位。
- **要出 3 张**：
  1. 正立面 1:20：完整影窗，含上下杆、边框、四角固定件、幕布垂褶走向；
  2. 上杆 + 下杆断面 1:5：杆径、杆与框的间隙、幕布如何固定（绳绑 / 压条 / 木楔三选一，画清楚）；
  3. 1:1 局部：幕布织纹、边缘包边、穿绳孔。
- **必须标注**：幕面净 900×800；幕布离框的距离（几厘米）；杆径；绷紧方式；换幕时人手可及的位置。
- **建模判据**：看完图我能直接建出「框料断面 + 幕布厚度 + 绷紧件」三组尺寸，不用再问。
- **不要**：把幕布画成整张发光；在幕面中央加纹样（会与投影打架）；把框做成纯平面。

### A2 · 台口：柱、梁、斗拱、檐口

- **对应槽位**：台口柱 120×120×1400 @(880,±820)；椽 4000×40×40 @z1800 ×8；檐口 72×2600×34 @z1946 ×3。
- **要出**：正立面 1:20（台口全貌，含幕窗在其中的位置）+ 侧剖 1:20（出挑深度、柱础做法）。
- **必须标注**：台口净宽约 1440；柱断面 120×120；檐口出挑尺寸；斗拱层数与层高；柱础高度。
- **建模判据**：斗拱能按「层数 + 每层出跳」建出来，不要求雕花细节。
- **不要**：把柱子画得比幕面还抢眼；不要加会挡住幕窗上沿的垂饰。

### A3 · 侧墙、壁柱、栏杆、台基、台阶

- **对应槽位**：侧墙 4000×50×1900 @y±1300；壁柱 70×70×1900 ×8；栏杆柱 40×40×520 ×5；台基 280×2500×30 ×3；台阶 90×150×25 ×3。
- **要出**：横剖（俯视）1:50 + 侧立面 1:50 + 一处 1:5 节点（壁柱与墙面交接、栏杆与台基交接）。
- **必须标注**：墙厚 50；壁柱间距与离墙距离；栏杆高度与柱距；台基每级高度与出挑。
- **建模判据**：能直接排出 8 根壁柱与 5 根栏杆柱的位置序列。
- **不要**：把侧墙做成整面雕花墙（性能与投影都吃不消），画成「大面 + 壁柱节奏」即可。

### A4 · 门楼与入场走廊

- **对应槽位**：门柱 80×80×920 ×2（y=-540/+120，净宽 620）；门楣 90×720×90 @z950；门槛 140×700×20；台前大门 40×560×1400 @x2180；走廊墙 500×30×400 ×2、柱 30×30×420 ×4、梁 30×640×20 ×2、顶 500×680×18。
- **要出**：正立面 1:20（玩家第一眼看到的样子）+ 轴测（门楼 + 走廊进深关系）。
- **必须标注**：门净宽 620、走廊净宽 610、门楣底高 950；门楼檐口出挑；走廊柱距；门槛高 20。
- **建模判据**：门洞与走廊必须能对上（610/620 两个净宽是硬约束），门楼装饰可在檐下与匾额区做。
- **不要**：把门洞画窄或画成拱门（是方门）；走廊两侧墙不可内收。

### A5 · 灯具三件套

- **对应槽位**：吊灯笼 球 60×60×90 ×7 每侧 + 吊绳 8×8×500 ×7；壁灯 球 40×40×40 ×3；路径灯 柱 34×34×250–286 ×12 + 灯球 30×30×34 ×12；檐灯 66 ×3、屋顶灯 50 ×3、门楼灯 115 ×2。
- **要出**：吊灯笼（正面 + 侧面 + 发光面展开）／壁灯（正面 + 侧面）／路径灯（正面 + 侧面 + 顶视）各一张；另附 1:5 节点：灯笼上下圈 + 竹骨排布 + 吊绳连接。
- **必须标注**：灯笼 60×60×90；竹骨数量与走向；纸面与骨架的厚度差；发光面范围（哪几片纸透光）；路径灯柱 250–286 的高度差与灯球位置。
- **建模判据**：能按图做出「竹骨骨架 + 纸面（可透光材质） + 上下木圈 + 吊绳」四件套；纸面要能单独换材质。
- **不要**：把灯笼画成整球发光（现在就是这个问题）；竹骨不要密到看不见纸面。

### A6 · 地板与台基铺装

- **必须标注**：单板宽、板长范围、缝宽、错缝规则、台口前沿的收边做法。
- **建模判据**：能按图用 4–6 种板型循环排出整片地面，不需要逐块手工摆。
- **不要**：画成瓷砖或石板（是木地板）。

### B1 · 山体三层剪影（近 / 中 / 远）

- **对应槽位**：主山 锥 2600×2600×1800 ×16；山脊 锥 3600×3600×1200 ×10；远山 锥 2200 ×14 / 2400 ×6；中景山 1440–3100 ×25；山裙 4200×4200×780 ×8。
- **要出**：一张并置剪影图（近 / 中 / 远三层，同一地平线），标每层高度、峰形差异、层间雾感强度。
- **必须标注**：每层典型高度（1800 / 1200 / 800 左右）、峰数、山脊倾斜方向、近景是否入画。
- **建模判据**：三层剪影能各自成一个可复用的「山片」网格，靠摆放与雾拉开层次。
- **不要**：画成写实照片式山体（会与皮影语言冲突）；不要每座山都长一样。

### B2 · 枯树：干、枝、冠

- **对应槽位**：枯树 柱 62×62×620 ×14 + 冠球 417×374×310 ×14；树变体 锥 92×92×560 ×16、球 274–354 ×28。
- **要出**：正立面 1:20（整树剪影）+ 分叉节点 1:5（主干分 3–4 枝的角度与粗细过渡）。
- **必须标注**：干高 620、冠径 417、分叉角度与分叉高度、枝梢收尖长度。
- **建模判据**：能按「干 + 3 档枝 + 冠」四层做出一棵，再用旋转/缩放出 14 棵不重样。
- **不要**：画成有叶的树（现在就是「球冠」问题）；不要对称。

### B3 · 山石组合

- **对应槽位**：山石 球 300×260×160 ×10、90 ×10、90 ×4。
- **要出**：45° 轴测一张，包含大 / 小两档尺寸（300 与 90），标苔痕/裂纹走向与埋地深度。
- **必须标注**：两档尺寸；埋入地面的比例（避免看起来是「放上去的球」）；主要裂纹走向。
- **建模判据**：能从一张图切出 3–4 块可复用的石头，靠旋转摆放。
- **不要**：画成圆润鹅卵石（是风化岩，要有硬边与切面）。
