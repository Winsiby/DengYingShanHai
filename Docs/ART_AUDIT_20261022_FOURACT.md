## 6. 第 3–5 条处理结果（Run4，2026-10-23 09:23）

三条都用"距离可读性"判定，而不是凭感觉改：先用 Blender 只加载 Run3 的分片顶点，渲染黑轮廓到 420 px 与 180 px，比较改法前后在远距离是否还能读出角色，然后才动源模型。

| 精卫翼杆 | `spar_px` 短支杆：翼杆终点落在翼内皮片，只有一根主杆收向握把，末端加黄铜握把球 | `../ThreePuppets-20261022/Run4/Jingwei/Preview_Rest.png`、`Final-Act2.png` |

Run4 三角面 16,024 / 8,168 / 8,028，骨骼 17 / 14 / 8，镂空 99 / 33 / 32，全部 `PASS-MODEL-SOURCE-FBX-ROUNDTRIP`；Run2、Run3 保留回退。

朝向也在本轮确定：三条 cast 条目统一 `rot yaw = 180`（与概念图一致——刑天斧在画面左、盾在右；烛龙侧脸朝左），`scale = 1.1`，夸父保持 0.8。

**回归教训**：`import_cast_ue.py` 每次导入都会重写 `DA_DYPuppetCast` 的四条 entry，早前版本用 `(0.0, 0.0, 0.0)` 旋转与 0.8 缩放把已校准的 yaw/scale 冲掉。现在脚本内固定 `XF = dict(loc=(0,-42.44,-104.57), rot=(0,0,180), scale=(0.8,…), cast_scale=(1.1,…))`。另注意 UE Python 的 `unreal.Rotator(a,b,c)` 位置参数顺序是 **(roll, pitch, yaw)**，写 `Rotator(0,180,0)` 会得到 pitch 180（倒立）而不是 yaw 180。
