# 复演者重设计：幕后的人，幕上的英雄

日期：2026-10-17。唯一人类作者与项目负责人：用户本人；Codex 为检索、设计整理、资产适配与技术验证辅助工具。

## 1. 本轮决定与实际完成边界

用户已明确否决当前绿色上衣 Sam 人物，要求重新设计并增加联网检索。**停止将该外观导入 UE，不以“许可明确、能动、有动画”替代美术合格。**旧源文件、技术测试与 GitHub 历史仍保留；可证明技术有效，不再代表人物外观获认可。

本轮完成的是：重设计说明、免费来源筛选和后续视觉验收标准。没有制作或下载新角色实包，没有新人物效果图、UE 导入、游戏替换或打包。本文描述的是设计目标，不能作为已经实现的画面。正文中的颜色、服装组合、人物气质均是原创提案，不是对传统服饰的史实断言。

## 2. 对旧外观的实际检查

已查看整理版正面与背面 Blender 渲染图，而非仅看资产标题。美术判断如下：

- 圆领绿色长袖、普通深色裤和棕色鞋的组合缺少本项目识别度，更像通用场景配角。
- 大面积平滑衣服、较弱的面料分层，以及当前脸部与头发观感，容易产生模板人／塑料人印象。
- 背面主要是无特征的大色块；第三人称长期看到的后脑、肩线、袖口和腰线没有得到足够设计。

这些是对当前可见样本的审美判断，不把制作软件、面数或许可证当作“不好看”的根因；也不能只靠换色、增加法线噪点或把画面调暗解决。

由上述资料得到的设计推论：人物的文化身份首先应来自“人—灯—杆—偶—幕”的关系；本轮没有找到支持“所有皮影艺人必须穿同一种长衫／古装”的依据。短外衫、低饱和配色、袖口设计是本游戏的原创选择。

## 4. 新设计主方向：灰青短衫的幕后复演者

一句话：**一位安静、利落的年轻成年人，在暖灯照亮的旧戏台幕后，让停下来的演出重新继续。**人物有完成度，但舞台、皮影与幕上结果仍是视觉主角。

不新增血统、师承、超能力、明确朝代或支线背景；不把玩家改成夸父。年龄气质是美术提案，不新增剧情事实。暂沿用青年人体制作候选，不因找到某个性别的现成模型而反过来固定角色身世，也不制作多角色选择系统。

| 部位 | 具体设计目标 | 避免的问题 |
|---|---|---|
| 体型与比例 | 接近真实成年比例，略作风格化；肩颈自然、体型匀称，四肢不夸张 | 大头玩具感、超级英雄宽肩、通用木偶身体 |
| 脸 | 温和专注、清楚的眼眶与颧颌体块；避免呆板凝视、蜡白皮肤和过强油亮 | 不用模糊面罩藏住失败的脸，不照真人肖像 |
| 头发 | 自然深色短发，前后都有分组体块与少量碎发；后脑轮廓要完整 | 光滑头盔感、过密透明片、飘逸仙侠长发 |
| 外衫 | 低饱和灰青／靛青、短下摆，轻微宽松但肩线清楚；简洁小领，实际结构由合规衣物原件决定 | 只给旧毛衣换颜色、宽袍大袖、硬贴盘扣 |
| 内层与袖口 | 米白内层在领口与袖口少量露出，袖口收束或短卷边，手腕清楚 | 手被衣料遮住、发白发光的大面积内搭 |
| 裤与鞋 | 炭灰直筒裤，膝部有合理松量；哑光深色低帮鞋，简洁薄底外形 | 牛仔高光、棕色亮皮鞋、战靴、大鞋底卡通比例 |
| 背面 | 重点做好后脑、肩部拼接、背部体积、下摆层次；一处小缝线／布签作为近看细节 | 全背空白，也不靠大徽章／龙纹填空 |
| 文化呼应 | 至多一处小面积、原创的日轮或影窗结构呼应，先不强制添加 | 混用道教符号、玉佩、刀剑、斗笠、巨型背包 |

配色目标而非未测试的 UE 材质定值：

- 灰青外衫参考 `#43585B`，备选稍深的靛青 `#354B62`。
- 米白内层参考 `#D3C8AF`，炭灰裤参考 `#34383C`。
- 只允许很小的赭红点缀参考 `#965044`，不设为必须有的腰带或新道具。
- 皮肤、衣料、鞋和头发用不同的表面响应分开，不能全靠颜色；织物纹理与磨损须与观看距离相符，不能靠巨大布纹证明“有细节”。

上述十六进制仅供设计沟通，不能不经色彩空间与灯光检查直接抄为线性材质参数。人物不做自发光；不能通过改亮主灯、篡改投影或换镜头来掩盖外观问题。

## 6. 接下来先验证外观，再做导入

唯一负责人：用户；Codex 执行设计整理与实现辅助，不新增制作成员。

1. 取得确切免费候选，保留原始压缩包、作者页、包内许可及哈希；先核实际模型，不启用来源不明的自动运行脚本。
2. 制作一个新外观样本，不扩成角色编辑器；做正面、背面、侧面和三分之四背面，灰青主色与靛青仅为同样本配色比较。
3. 同时提供中性照明与接近当前暖色舞台的照明对照，明确是 Blender 样本还是 UE 截图。不得用一张概念图替代实际网格。
4. 先检查脸、后脑、肩颈、袖口、手、衣服层次与鞋；摆脱旧模板外观后，才进入独立 Dev 导入。不好看就继续标候选，不能以骨架测试全绿跳过美术判断。
5. UE 阶段保留当前真实 POV，测试冷暗后台轮廓、暖灯边缘光和幕前明暗关系；不牺牲灯／偶／幕可见性换角色特写。
6. 之后才核 Idle／移动／起停／转向／操纵／切幕／复位／重演；旧动作不因已有数值测量就默认适配新骨架。不得改360cm/s、150cm步距或2cm起步音效门来迁就外观。

本轮不改 C++、Pawn、GameMode、地图、Config、输入、谜题、镜头、音效、包或任何 `.uasset`。后续新源资产另建版本目录，旧源不覆盖、旧候选不删除。设计文档完成不等于新模型阶段完成；新模型阶段有真实视觉证据后再按既定流程提交 GitHub。

## 7. 新人物最低美术验收

- 仅看背影就能看出是设计过的人物，不是绿色便服模板人，也不是大头低模玩具。
- 中性光和暖色环境光下都能看清头脸体块、头发分组与面料层次；不靠后期糊脸、过曝或压黑隐藏缺陷。
- 操杆相关手腕、手指不被衣服挡住；衣服动作不穿插，外套下摆不遮腿，不引入需要复杂布料模拟才能成立的长摆。
- 人物与暖木、旧布、皮影的材质语言协调，但不抢过幕上演出。
- 模型、贴图、绑定与动画实际取得、许可逐项清楚；文化参考图不被当作可再分发资产。
- 实际 UE 图、动态与打包检查仍是后续门槛，不能以本设计文档关闭整个角色或竞赛美术里程碑。
