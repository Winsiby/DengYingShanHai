# FullSpan beam: local source artifact

Reuses the existing CC0 VVayToyek Chinese Four-corner Pavilion beam and existing CC0 Poly Haven Dark Wood texture family. Upstream source and license evidence remain in project Docs/FRAME_BEAM_ASSET_SOURCES.md and FRAME_POST_ASSET_SOURCES.md; this task did not access the restricted register. No download, payment or new texture.

Codex assisted with data-only adaptation: translate the left beveled end rigidly, extend only four straight faces, translate four left UV islands to retain existing wood sampling density. Original pavilion authorship is not claimed. No historical joinery, load-bearing structure or particular shadow-theater tradition is asserted.

DERIVATION.json contains exact source/tool/helper/output hashes, the complete author-tool source, all node-property comparisons and a fresh physical FBX parse. Only Vertices and UV array properties change. This is source-only validation, not native import, gameplay, collision, final lighting, GPU or artistic acceptance.
