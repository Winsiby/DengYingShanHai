## 1. 本轮起点与退出边界

用户已签收字号与新版“开始 → 三幕 → 成林 → 重演 → 第二轮 → 退出”正常路径。技术基线是 EntryLoop Run2、111/0 原生回归、上一闭环的 37 项可见检查及两次真实成林。不把上述正常路径解释成独立 R、失焦、盲测、性能、声音、Skip、完整剧场或 Shipping 验收。

下一项的可见目标是：首次玩家不依赖调试数值，能指出本幕应观察哪一个幕上关系，并用原有操作调整。仅做可读性候选，不直接锁定正式美术、体验时长或教学效率。

## 2. 已核实的实际接口，不按旧设计猜测

- `UDYInteractionHUDWidget` 已提供“继续调整 / 影形渐合 / 保持此刻 / 影形未稳，再试一次”，以及三幕题签与结尾文案。不重复开发第二套反馈或 Holding 计时器。
- `FDYActSequenceSnapshot` 只有序列开启、幕次、题签、Phase，没有 Target、Tolerance、Progress 或控制对象。玩家 UI 不能从这个接口得到答案；本步不得扩大它为数值面板。
- `ADYStagePresentation` 有真实 Blueprint 事件 `ReceivePuzzleActivated`、`ReceiveFeedbackStateChanged`、`ReceiveHoldStarted`、`ReceiveHoldCanceled`、`ReceivePuzzleResolved`。可读性样本应复用已有表现事件，并审查复制 Blueprint 的实际连接，不能臆造节点。

## 3. 已确认方案与保留的对照

| 方案 | 玩家看见什么 | 优点 | 需要验证的风险 |
|---|---|---|---|
| A：幕上局部线索＋一句动作提示（推荐） | 残日/山口局部线、追日方向与角色所在区域、既有 Z70 地线上的落杖线索 | 目标留在主要阅读区，服务灯偶幕关系；能逐步减少文字 | 线索可能被误读为真实影子，或遮住影形；需要实际机位校准 |
| B：幕边关系示意卡＋一句动作提示 | 小型“灯—日 / 偶—身形 / 灯偶组合”的关系图示，不显示精确目标参数或完整答案轮廓 | 不覆盖幕上关键投影，示意层与真实影子更容易区分 | 玩家需在卡片与幕布之间切换注意，可能仍依赖图示 |

推荐 A 的依据是现有 GDD 明确要求山纹缺口/残日线索与实际幕布观察，而非仪表盘。这里不采用完整人物答案描边，不承诺未接入的姿态教学。B 是有效的对照候选，不是降级为长篇教程。

A 的阅读任务（Dev 候选，尚不等于首次玩家盲测已通过）：

1. 引日启幕：只提供局部残日/山口位置线索，提醒观察“灯动，影变”。皮影保持现有固定规则。
2. 逐光成形：提供日与角色的空间关系线索，提醒在灯与偶之间协同；不给某个单变量“已通关”的假绿灯。
3. 杖落成林：复用前两幕的阅读方式，强调既有幕上地线和持杖构图；第三幕仍是直接双变量组合，不新增顺序锁定或切姿态输入。

用形状/位置/明暗区分线索，不只依赖颜色。保持真实主灯阴影为玩家成果；提示几何默认不投关键阴影，不用贴图冒充实时角色。

## 5. 所有权、生命周期与依赖方向

```text
Director（唯一判定/幕次/保持/完成）
  → 已有 Stage Presentation 的事实后事件
    → Readability 的 Stage Blueprint 副本
      → 明确引用的目标线索 / 被动提示视图

本地 PlayerController → 开始/结束菜单焦点与当前允许地图重演
```

- Stage 副本拥有线索的显示/隐藏，不另建 Guide Director、Subsystem 或 GameInstance 进度。
- 目标元素只包含作者配置的形状与 Transform，不读取 Director，不做判定或写灯偶参数。仅在本地图存在，切幕/复位/世界销毁时清理。
- 玩家 HUD 继续读无答案快照。可读性表现不消费每帧 Progress 连发，也不加 UI 属性轮询或世界扫描 Tick；使用已有离散状态和显式引用。
- 迟到显示按已有当前快照恢复；重复状态应用幂等。重演销毁旧 World、委托和线索，不保留 CDO 运行标记。
- 单机本地表现，不做复制或存档。PlayerController 唯一管理输入模式；不新增 POV 所有者，不改变当前机位。

选择直接引用/既有事件的原因是单地图一套明确对象关系。不需要全局消息总线或新接口发现系统。

4. 从保存后的 Blueprint 和地图冷读事件连接、明确引用、字形、可见性/碰撞/阴影设置；不得重新保存原件。
5. 正常视图检查第一眼焦点、灯偶幕双空间、线索与影子可区分、Holding/打断/Resolve/复位、切幕隐藏、接触前无林、真实成林和重演无残留。调试信息作为独立证据，不作为玩家唯一导航。

7. 作者签收后邀请未参与开发者做首次玩家盲测，记录理解、卡点、完成时间和提示介入。没有盲测就不写“首次玩家多数能完成”，也不据灰盒测试设定正式 5–8 分钟。

通过条件：无需开发参数即可指出当前目标关系；能区分“我造成的影子”和“舞台线索”；三幕仍为发现规律/协同控制/综合运用；原参数和输入不变；落杖从当前最终状态继续、真实接触后成林；结束/重演/旧入口均正常。

## 9. 真实画面校准与尚未解决的设计证据

运行采样基于真实 BeginPlay 与逐幕配置：.15/.15、原目标中心及进入容差邻域。同步采样后在同帧恢复控制值；由保存的生产流程完成保持、切幕和成林，不制造成功或接触 Token。

截图显示幕布亮点包含材质高光，不能把它当成灯锥轴线的可靠几何标记。因此最终候选将局部残日弧/缺口围绕实际头部投影摆放，动作句直接指向偶影；不再要求把高光亮点精确移到数学轴心。第二、三幕补充开放角标，第三幕短标来自原目标 A 端幕上投影 Y 与已确认 Z70 地线。成功后线索隐藏，不干扰真实落杖与林影。
