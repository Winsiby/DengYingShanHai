怎么判断它是否更合适

先看横梁顶面长向木纹是否减少拉伸，再看右柱接合和整体轮廓。顶面源 2K 局部度量约 140.114→198.152 texel/m，横向保留约 198.152；上一阶段近景差异较明显，中远与暗光下差异有限。
