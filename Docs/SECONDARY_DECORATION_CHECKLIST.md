日期：2026-10-19。

本清单用于次要装饰资产的制作、筛选与接入，数量均为建议值。已有的厚侧幕、操杆挂架、后台长凳、灯具和木地板继续复用，不重复制作。

## 2. 建议制作顺序

1. **内侧布幕 → 灯轨及配重 → 小工具台**：先补齐后台的用途和层次。
2. **操杆 → 少量纹样 → 远景剪影**：加强影戏特征与空间感。
3. **锣鼓、卷轴、皮影箱等小道具**：最后按画面需要添加。

## 3. 统一制作要求

- 纯装饰，不新增交互、谜题或输入。
- 操杆沿用现有骨骼，不另建骨骼体系。
- 优先复用现有木、布、纸、铜材质。
- 外部资产使用许可清晰的免费／开源资源，保留来源与许可说明。
- 不遮挡主幕、目标提示、夸父主体和玩家路线。
- 远景与纯装饰件不设置不必要的碰撞；避免非必要动态投影。
- 装饰仅服务现有同一座小剧场，不增加房间、可探索区域或新玩法。
