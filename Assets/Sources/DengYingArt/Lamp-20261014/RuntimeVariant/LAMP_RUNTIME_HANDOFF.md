# 运行时重采样变体

完整源资产保留，未使用 Decimate。本子目录通过解析圆环、圆柱、圆罩与倒角采样降低三角面数量，属于经过视图审核的视觉保真近似，不能称为几何无损。

| 网格 | 完整源 triangles | 变体 triangles |
|---|---:|---:|
| 灯身 | 53,680 | 20,016 |
| 支架 | 40,032 | 13,088 |
| 合计 | 93,712 | 33,104 |

减少 64.68%。没有硬凑 20k：前缘大圆环保留 80×12 采样，光学片压圈保留 64×8，其他小圆环为48×8；圆罩周向128→64，默认柱与木杆96→48，小圆柱32→24、48/64→32，倒角4→3段。全部参数差异和完整源前后 SHA256 保存在 `RUNTIME_PARAMETER_DIFF.json`。

保留57个结构部件、原纵向轮廓、半径、厚度、倒角宽度、材质分区、UV规则、锚点和相机。两件 FBX 的 Actor-local 包围盒与完整源相同；光源前方净空3 cm，支架保留原局部Z=-95 cm枢轴，装配后底面Actor-local Z=-310 cm。

`Lamp_Head_A_Source.png` 是完整源近景的字节相同拷贝，`Lamp_Head_B_Runtime.png` 是变体近景。A/B严格使用同一相机：位置(2.4,-2.8,0.85)m、目标(0,0,-0.17)m、正交范围1.47m、1920×1440；灯、世界、AgX、曝光0、Cycles80采样及材质节点保持一致。`Lamp_Head_AB.html` 可在本地浏览器查看并拖动叠加比较。完整源与变体各自全景/侧面也保留。

推荐技术试导入使用本目录两件 FBX；完整 `.blend` 是美术母源，变体 `DY_HeroSpotlight_RuntimeVariant.blend` 仅是采样派生版本。UE接入变换、材质覆盖、查询碰撞与未验证范围仍以父目录 `LAMP_HANDOFF.md` 为准。拟建铜材质与复用经核验木材父材质需按真实资产路径接入；没有宣称 Blender程序铜材质可被FBX自动转换。
