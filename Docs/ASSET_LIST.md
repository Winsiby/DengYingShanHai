# ASSET LIST｜资产清单与交付约定

## 1. 使用方式

本项目为单人制作：全部资产与视频条目的唯一人类负责人均为用户。表中“制作/交付”包含免费合规资源获取、筛选和适配，不代表必须从零手工建模。AI 仅辅助；不能把外部资源或字体冒称原创。当前资产状态不得因责任表修正而自动变为完成。

本表是制作清单，不表示任何外部资产已经取得授权。每个资产进入项目时都应补充：负责人、状态、源文件位置、引擎路径、来源/作者、许可和版本。

优先级：

- P0：没有它就无法完成核心体验或录屏；
- P1：明显提升最终表现，应在内容锁定前完成；
- P2：有时间再做，可直接删减；
- 禁止扩张：不进入当前竞赛版本。

状态建议：`未开始 / 制作中 / 待接入 / 已接入 / 已验收 / 已降级`。

## 外部资产来源约束（2026-10-01）

候选来源、文化参考、许可边界、负责人和逐项验收流程见 `Docs/ASSET_SOURCES.md`。本清单中的每个外部资产必须同时填写：作者/发布者、具体资产页、下载日期、许可名称与版本、许可链接、修改内容、项目内路径、使用位置和许可页存档路径。

- 夸父核心皮影以《山海经》原文和公版《古今图书集成·夸父神图》为依据定向制作 2.5D 关节模型，不再使用通用皮影人物代替；戏台优先使用 CC0 四角亭、CC0 木材和 UE 基础几何；树木优先选择许可清晰的免费或 CC0 备选；灯具、道具、声音和字体只按“公版/CC0/OFL/免费明确许可”的顺序获取，不设置付费回退。具体见 `Docs/KUAFU_VISUAL_RESEARCH.md` 与 `Docs/ASSET_ACQUISITION_PLAN.md`。
- 通用纹理/HDRI：优先 Poly Haven 或 ambientCG 的 CC0 资产。
- 字体：优先思源宋体/思源黑体，按 SIL OFL 1.1 归档许可。
- 通用音效：Freesound 只选具体页面明确标注的 CC0 或 CC BY；不采用 CC BY-NC 与 Sampling+。
- UE 就绪资产：Fab 逐项核对 Standard 或 CC BY，不得只凭“免费”标签判断。
- 博物馆/非遗媒体：只有具体媒体明确标注 Public Domain/CC0 才能复用；其余只作研究参考。
> **硬性要求（2026-10-01）**：正式资产必须是团队自制或许可清晰的免费/开源资产；本项目不购买任何资产。所有外部资产在进入正式目录前必须完成许可登记和打包验证，具体见 `Docs/FREE_ASSET_POLICY.md`。
